# 侧窗 · SideBrowser

**侧窗小境，意赴遐荒。**

[English](README.md) · 简体中文

侧窗将你常用的网站放进 Chrome 和 Microsoft Edge 的原生侧边栏。主页面继续写作、阅读或研究，侧边打开 AI、搜索、资料和文档，减少来回切换标签的打断。

[从 Chrome 应用商店安装](https://chromewebstore.google.com/detail/jlankbdlgdjliaccjkhccphfjmmpgkho) · [官网](https://yuzhouu.github.io/side-browser/) · [问题反馈](https://github.com/yuzhouu/side-browser/issues)

## 常用工具，就在手边

- **边工作，边问 AI。** 在侧边打开兼容的 AI 网站，手动输入问题或粘贴材料，主页面始终留在眼前，方便对照和继续工作。AI 服务由你选择的网站提供，侧窗不会自动将主页面正文发送给它们。
- **查资料，不离开当前页面。** 一边阅读或写作，一边搜索、查文档、看参考资料。
- **切换标签，侧边网页继续运行。** 同一窗口内的未绑定标签共用一个侧窗网页，切换时保留输入、滚动位置和网页状态。关闭最初提供网址的标签，也不会关闭共享侧窗网页。
- **给一个标签配上专属网页。** 在「更多」中将当前侧窗绑定到某个标签，该标签便拥有独立网页和导航历史。其他未绑定标签回到欢迎页，你可以重新打开一个共享网页。不同浏览器窗口各有自己的共享网页与历史。

## 快速找到、重新打开网页

- **一个地址栏，输入网址或搜索。** 支持 Google、Bing、百度和 DuckDuckGo，可在设置中选择搜索引擎，默认使用 Google。
- **边输入，边查找。** 地址联想汇集侧窗收藏、最近打开、浏览器历史和书签，标明来源，支持方向键选择、Enter 打开和 Escape 收起。
- **常用网站，收藏即达。** 从「更多」收藏当前侧窗网页，也可通过右键菜单收藏网页。收藏以网站图标显示在欢迎页，悬停或键盘聚焦可查看标题和完整网址，点击即可打开。侧窗收藏与浏览器原生书签分开保存。
- **最近打开的 10 个网址。** 点击地址栏旁的时钟按钮快速重开，支持单条删除和清空。收藏与最近记录跨窗口共用，重启浏览器后仍会保留。

## 日常浏览操作，一步可达

一键打开当前网页，也可使用网页／链接右键菜单，或按 **Alt + Shift + P**（Mac：**⌥ + ⇧ + P**）。简洁的顶部导航栏提供后退、前进、地址输入和关闭当前网页。

关闭网页后回到欢迎页，保留收藏、最近记录、偏好和已有的标签绑定。也可以从「更多」将侧边网页放到普通新标签页继续浏览。

按需切换**手机／电脑视图**，选择**浅色／深色／跟随系统**外观。这些偏好跨窗口共用；切换视图会刷新运行中的侧窗网页，切换外观不会重新加载。网页是否响应外观变化取决于网站自身。

界面自动跟随浏览器语言，支持简体中文、繁体中文、英文、日语、德语、法语和西班牙语。

## 开始使用

1. 使用 **Chrome 145 或更高版本**，从 [Chrome 应用商店](https://chromewebstore.google.com/detail/jlankbdlgdjliaccjkhccphfjmmpgkho) 安装侧窗。
2. 将侧窗固定到工具栏，点击图标打开侧边栏。
3. 输入网址或搜索关键词，或选择「打开当前网页」。

侧窗可免费安装，无需注册侧窗账号。所打开的网站可能需要独立登录或订阅。更多使用说明见「更多」→「关于与帮助」。

## 数据由你掌握

收藏、最近记录、偏好和网页恢复数据保存在本机。地址联想只在本地查询浏览器历史和书签，不修改它们。侧窗不向开发者上传你的记录，没有遥测或开发者运营的代理服务器；网页与搜索请求发送给你选择的网站和搜索引擎。

详细说明见[隐私政策](docs/privacy-policy.md)。

## 网页兼容与状态恢复

部分网站限制嵌入浏览，或受登录与第三方 Cookie 设置影响。如果网页无法在侧窗正常使用，可从「更多」在普通新标签页打开。手机视图用于网页显示适配，不等同于完整设备模拟。

侧边栏保持打开时，切换标签会保留正在运行的网页。关闭侧边栏或重启浏览器后，可以恢复保存的网址，但不保证恢复表单输入、滚动位置或未发送内容。标签绑定仅在当前浏览器会话有效；解除绑定或关闭已绑定标签，会关闭对应的独立侧窗网页。

## Microsoft Edge 安装

Chrome 与 Edge 共用同一份扩展包。使用当前桌面版 Edge（Chromium 145 或更高版本），在 `edge://extensions` 开启「开发者模式」，点击「加载解压缩的扩展」，选择构建后的 `dist/` 或 ZIP 解压后包含 `manifest.json` 的文件夹。Edge Add-ons 商店尚未上架。
